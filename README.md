# Koyeliya - Our Scrapbook

A digital love letter, a scrapbook of our moments together, and a journey through our universe. Built with love, React, Next.js, and Tailwind CSS.

## Features

- **The Journey:** A scrolling, looped scrapbook of our highlights.
- **Our Stars:** A celestial view of our constellations.
- **The Scrapbook:** A collection of memories.

## Setup

This project uses Next.js and Tailwind CSS. It is configured for standard deployment on platforms like Vercel.

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Design

Inspired by vintage love letters, with a warm color palette, handwritten fonts, and subtle paper textures.
